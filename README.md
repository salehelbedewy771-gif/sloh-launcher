# SLOH Launcher Website

A responsive landing page and visual concept for the independent SLOH Launcher project.

## Preview locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy with Vercel
1. Import this repository into Vercel.
2. Keep the framework preset as **Other**.
3. Leave the build command and output directory empty (static site).
4. Deploy.

## Project status
This repository currently contains the website concept. It does not contain a launcher installer or a completed launcher application. The site intentionally does not advertise a fake download.

SLOH Launcher is an independent project and is not affiliated with, endorsed by, or sponsored by Mojang or Microsoft.
