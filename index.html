ABOUT THE PROJECT

Built for the
love of the game.

SLOH Launcher is an independent project exploring a simpler way to organize and start Minecraft. The aim is a launcher that feels modern, stays approachable, and respects your setup.

We're sharing the concept while development moves forward. Features shown here describe the project's direction and are not a claim that a finished launcher is available today.

GOOD TO KNOW

Questions? Answered.

Can I download SLOH Launcher now?+

Not yet. A public installer has not been released. We'll add a verified download link here when a real release is ready.

Is SLOH Launcher an official Minecraft product?+

No. SLOH Launcher is an independent community project and is not affiliated with, endorsed by, or sponsored by Mojang or Microsoft.

Will it support mods and different versions?+

Version organization, profiles, and mod-friendly workflows are planned goals. Exact compatibility will be documented when implemented and tested.

Where can I follow development?+

Visit the public GitHub repository for project updates, source files, and future release information.
